# FABMP价值分析与证据准备

Copyright (c) 2026 tecoatwork

## 用途与方法

FABMP价值分析与证据准备。具体工作流程、证据规则及边界见 [SKILL.md](SKILL.md)。

## 输入

行业、产品Feature、客户类型、职位、目标市场；具体公司、历史沟通和已有证据可选。

## 交付

客户需求与优先级摘要、FABM价值分析表、P证据准备清单、可用的价值表达。

## 安装与启动

下载本仓库并先审查文件，将整个 `teco-fabmp-value-analysis` 文件夹放入所用助手支持的 Skill 目录，保留 `SKILL.md` 与 `agents/openai.yaml` 的相对位置。Codex 用户可放入 `~/.codex/skills/`；其他工具以其实际支持方式为准。

启动示例：

> 请使用 teco-fabmp-value-analysis。你好，请你告诉我，需要提供什么信息给你。

也可以直接提供输入，Skill会复用已有信息，仅询问关键缺项。

## 依赖与边界

无执行脚本或额外软件依赖。外部研究需要助手具备联网检索能力；本地笔记需要文件读取权限。无法获取的信息会明确标为未核实。只做研究与草稿，不自动发送、修改商业条件或创建自动任务。

## 验证范围

已做格式校验、文本和配置静态审查；这不代表所有模型、平台或销售场景均已实测，也不保证回复或成交结果。
